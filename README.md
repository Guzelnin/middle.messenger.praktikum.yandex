# Messenger

Учебный проект клиентской части мессенджера.

Демо: [dynamic-clafoutis-808e9b.netlify.app](https://dynamic-clafoutis-808e9b.netlify.app/).

## Возможности

- Вход, регистрация и выход через HTTP API.
- Защищённые маршруты: без активной сессии доступны только вход и регистрация.
- Просмотр профиля, изменение данных и пароля, загрузка аватара.
- Загрузка списка чатов, добавление пользователя по логину и удаление чата.
- Клиентская навигация с поддержкой истории браузера.
- Валидация полей форм.

Запросы отправляются через `XMLHttpRequest` с Promise; API-клиент поддерживает `GET`, `POST`, `PUT` и `DELETE`. Используется учебный API Яндекс Практикума: `https://ya-praktikum.tech/api/v2`.

## Требования

- Node.js 20.19 или новее
- npm

## Установка и запуск

```bash
npm install
npm run dev
```

Vite запустит приложение на `http://localhost:3000`. Порт можно переопределить переменной окружения `PORT`.

`npm run start` сначала проверяет типы и собирает production-версию, затем запускает Vite. `npm run build` проверяет типы и создаёт production-сборку в `dist/`.

## Команды

| Команда              | Назначение                                                     |
| -------------------- | -------------------------------------------------------------- |
| `npm run dev`        | Запустить сервер разработки Vite                               |
| `npm run start`      | Собрать проект и запустить Vite                                |
| `npm run build`      | Проверить типы и собрать production-версию                     |
| `npm run preview`    | Просмотреть production-сборку                                  |
| `npm run prebuild`   | Проверить TypeScript без генерации файлов                      |
| `npm run lint`       | Проверить TypeScript, стили через Stylelint и код через ESLint |
| `npm run format`     | Проверить форматирование Prettier                              |
| `npm run format:fix` | Форматировать файлы через Prettier                             |
| `npm run check`      | Выполнить сборку, линтеры и проверку форматирования            |

Автоматический тестовый скрипт в проекте пока не настроен. Команда `npm run check` не заменяет функциональные тесты API.

## Архитектура

- `src/api` — XHR-транспорт и методы HTTP API.
- `src/controllers` — обработка событий, запросов и состояния интерфейса.
- `src/views` и `src/pages` — рендеринг страниц на Handlebars.
- `src/components` — переиспользуемые UI-компоненты и базовый класс `Block`.
- `src/constants`, `src/types`, `src/utils` — маршруты, типы, валидация и вспомогательные классы.

Для ручной проверки создавайте отдельный учебный аккаунт и используйте только тестовые данные.
